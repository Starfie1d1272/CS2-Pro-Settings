# 微信公众号发布指南

## 格式
公众号编辑器不支持 Markdown，需要：
1. 用 135编辑器/秀米 等第三方工具排版
2. 或者先把 Markdown 转成富文本再粘贴

## 拆分为上下两篇
全文 4000+ 字太长，影响完读率。建议拆分：

**上篇**：背景 → Q1(eDPI) → Q2(DPI/Sens) → Q3(刷新率/FPS) → Q4(准星)
**下篇**：Q5(持枪视角) → Q6(分辨率/亮度) → Q7(画质) → Q8(雷达) → 总结

## 注意事项
- **正文字号**：15px，行间距 1.75
- **图片**：宽度统一 100%（撑满屏幕宽度），公众号会自动压缩，原图不超过 10MB 即可
- **封面**：2.35:1 比例（900x383），用 `eDPI.png` 裁剪
- **标题**：要在 20 字以内抓眼球，比如"198名职业哥的数据，我总结了8条设置铁律"
- **底部**：放 GitHub 链接和个人简介引导关注
- **原创声明**：可以声明原创
