# reports/

Deterministic bilingual monthly snapshot reports — **machine-generated, not
human-edited**. Every file here is produced deterministically from the
pipeline's snapshot/report inputs (aggregate + drift + run context) and is
committed as an accepted artifact. Future same-series reports depend on
run context (drift, roster turnover, matched panel, source/conflict state)
that is not part of the public aggregate, so they are generated by the
pipeline — `scripts/render_accepted.py` is a limited backfill tool for the
first `vrs-core-v2` baseline only.

Reports are **data-first**: they answer "what settings do the pros use this
month?" — not methodology. Sections appear only when there is real data to
show; missing fields, absent conflicts and first-baseline states hide their
sections instead of printing empty tables.

## File contract

- `latest.md` — English canonical report for the latest accepted snapshot.
- `latest.zh-CN.md` — Chinese report for the latest accepted snapshot.
- `YYYY-MM.md` / `YYYY-MM.zh-CN.md` — standardized v2 monthly archive
  (English + Chinese). Monthly archives reference their own immutable
  figure archive `figures/YYYY-MM/`, so a later snapshot never changes what
  an earlier month's report shows.
- `2026-05.md` — **historical legacy report**, preserved in its original
  form. It is not a v2 standardized report and is never rewritten.

## Properties

- Standardized bilingual reporting starts with **2026-08** (the first
  accepted `vrs-core-v2` snapshot).
- English and Chinese versions are rendered from **one shared view model**
  (`build_report_view`); denominators, coverage and section visibility are
  computed once and only the wording differs.
- Reports are **deterministic**: no LLM is used; interpretation sentences
  are fixed factual statements or are omitted.
- Content rules: no causal-advantage claims, no statistics-concept
  explanations, no methodology chapters, no duplicate statements.
- Human/editorial, platform-specific writing lives under `social/`, never
  here.
